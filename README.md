# Azure-Cost-Management-Budget-Monitoring
# PROJECT OVERVIEW -
## This project demonstrates how Azure cost Management can be used to monitor cloud spending, analyze costs, create budgets and configure cost alerts.
# OBJECTIVES -
## Monitor Azure Subscription costs
## Analyze costs by resource
## Analyze costs by service
## Monitor monthly cost trends
## Track costs by resource group.
## Create a monthly spending budget
## Configure a budget alert
# AZURE SERVICES & FEATURES USED -
## Azure Cost Management
## Cost Analysis
## Budgets
## Cost Alerts
## Azure Advisor
# IMPLEMENTATION -
## 1. Cost Analysis -
## Created cost analysis views to monitor :
## Cost by Resource
## Cost by Service
## Monthly cost trend
## Cost by Resource Group
## 2. Budget Configuration - 
## Created a monthly budget :
## Budget : AED 50
## Reset period : Monthly
## Alert threshold : 80%
## The alert is designed to notify when actual spending reaches AED 40.
## 3. Azure Advisor :
## Checked Azure Advisor for cost optimization recommendations. Azure Advisor recommendations may take time to become available depending on subscription activity.
## SKILLS DEMONSTRATED
## Azure Cost Monitoring
## Cloud cost Analysis
## Budget Management
## Cost Alert Configuration
## Resource- level cost tracking
## Basic cloud cost governance
## Azure cost optimization awareness
## PROJECT OUTCOME -
## Successfully configured Azure Cost Management to monitor cloud spending and created a monthly budget with an automated cost alert.
